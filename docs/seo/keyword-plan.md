# キーワード計画（記事の作成予定）

毎日のSEOタスクは、この表の上から順に「未着手」の記事を1本書きます。書いたら状態を「公開」にし、スラッグを記入します。
順番を変えたいときは、行を入れ替えるだけで構いません。

## 選び方の方針
- 大きいキーワード（「ドローン点検」単体など）は、国交省・大手・ポータルが上位にいて勝ちにくい。**2〜4語の具体的な検索語**を狙う。
- 問い合わせに近い順に優先する。費用、業者の選び方、法令の義務、地域名などを含む検索語を先に書く。
- 継続案件につながるテーマを厚くする。太陽光の年次点検（O&M）と、建設現場の定期撮影。
- 実績がないうちは「当社の事例」と書けない。一般的な解説、判断基準、チェックリスト、費用の考え方で勝負する。
