工場・倉庫の雨漏りは、**室内で水が落ちてくる場所の真上が原因とは限りません。** 屋根の上で入った水が、下地や部材を伝って離れた場所に落ちることがあるためです。まず室内側で雨漏りの位置と出方を記録し、次に屋根全体の状態をドローンなどで確認して、原因の候補を絞り込みます。最終的な特定には、散水試験などで確かめる方法が使われます。

## 雨漏りの原因になりやすい場所

工場・倉庫に多い折板屋根（金属の板を山型に折った屋根）やスレート屋根では、次のような場所が原因になりやすいです。

| 場所 | 起きやすいこと |
| --- | --- |
| ボルト・ビスまわり | さびによる穴、パッキン（ワッシャー）の劣化、ボルトのゆるみ |
| 屋根材の重ね目 | 重ね部分のすき間、シーリングの劣化 |
| 棟（屋根の頂上）・けらば・軒先 | 板金の浮き・ずれ、強風によるめくれ |
| 雨樋・谷樋 | 落ち葉や土の詰まりによるあふれ、継ぎ目の外れ |
| 天窓・明かり取りの屋根材 | 樹脂の割れ・劣化、周りの取り合い部のすき間 |
| 設備の貫通部 | 配管・ダクト・架台の足元のすき間 |
| 外壁との取り合い | 屋根と外壁の境目の板金やシーリングの劣化 |

とくに雨樋の詰まりは、あふれた水が建物の中に回り込むことがあり、屋根材に穴がなくても雨漏りにつながります。

## 原因を絞り込む手順

1. **室内側の記録**：雨漏りの位置（柱の番号や通り芯など）、雨の強さ・風向き、雨が降り始めてから漏れるまでの時間を記録します。強い雨や特定の風向きのときだけ漏れる場合は、手がかりになります。
2. **屋根全体の確認**：屋根材のさび・穴・ずれ、ボルトまわり、重ね目、雨樋の詰まりなどを、屋根全体で確認します。室内の雨漏りの位置と、屋根の上の気になる箇所を図の上で照らし合わせます。
3. **候補の確かめ**：候補の場所に水をかけて漏れるかを確かめる散水試験などで、原因を特定します。
4. **修理の検討**：部分的な補修で済むか、屋根の広い範囲の改修が必要かを、修理を担当する会社と検討します。

ドローンが役に立つのは、主に手順2です。屋根全体の状態を写真で記録しておくと、修理会社への相談や見積の比較もしやすくなります。

## ドローンで屋根を確認するメリット

- **人が屋根に上らない**：折板屋根やスレート屋根は、劣化した部分を踏み抜くおそれがあります。ドローンなら、人が上らずに確認できます。
- **広い屋根を短時間で**：大きな倉庫の屋根でも、全体を上空から撮影できます。
- **場所を図で共有できる**：写真に撮影位置と番号を付けて整理するので、室内の雨漏りの位置と照らし合わせやすくなります。
- **稼働を止めずに済む場合がある**：飛行する範囲の下に人が入らないように管理できれば、操業中でも実施できる場合があります。

屋根点検の全体像は [工場・倉庫の屋根点検](/guides/factory-roof-inspection) で解説しています。

## ドローンだけでは分からないこと

- 屋根材の裏側や、下地・断熱材の状態
- 水が入ってから室内に落ちるまでの経路
- ボルトのゆるみやパッキンの傷み具合（近くで触って確かめる必要がある場合）

ドローンの撮影結果は、散水試験や近接での確認を**どこで行うか**を決める材料として使います。

## 雨漏りを見つけたら早めに

雨漏りを放置すると、保管している製品や設備が濡れるほか、屋根材や下地のさびが進み、修理の範囲が広がることがあります。台風や大雨のあとに急に漏れ始めた場合は、[台風・強風のあとの屋根の被害確認](/guides/typhoon-roof-damage-check) もあわせてご覧ください。
