ドローン点検の報告書は、**「どの場所の」「どんな状態が」「写真のどこに」写っているかを、後から誰でもたどれる形に整理したもの**です。点検の結果を、修繕の見積依頼や社内の報告、次回の点検との比較にそのまま使えます。依頼する前に、報告書に何が載るのかを知っておくと、依頼先を比べやすくなります。

## 報告書に載せる主な内容

当社の基本報告書で整理する項目は、次のとおりです。報告書の形式や項目は、ご要望に応じて相談できます。

| 項目 | 内容 |
| --- | --- |
| 点検の概要 | 施設の名称・所在地、点検の目的、撮影日、撮影した範囲 |
| 撮影の条件 | 天候、撮影の時間帯、使用した機材（可視光・赤外線など） |
| 撮影位置図 | 建物の図の上に、写真を撮った位置と向きを番号で示したもの |
| 写真 | 全体の写真と、気になる箇所の拡大写真。写真に番号を付けて整理 |
| 異常の候補の一覧 | 劣化や異常が疑われる箇所を、場所・写真番号・状態のメモで一覧にしたもの |
| コメント | 気づいた点、優先して確認したい箇所、追加の調査が必要と考えられる点 |

報告書のイメージは、当社トップページの「報告書イメージ」でも確認できます（架空の建物を使ったサンプルです）。

## 写真と位置図の見方

報告書では、**位置図の番号と、写真の番号がそろっている**のが基本です。

1. 位置図で、気になる場所の番号を探します。
2. 同じ番号の写真を開くと、その場所の状態が分かります。
3. 異常の候補の一覧で、その番号に付いたメモ（ひび割れ、さび、浮きの可能性など）を確認します。

番号でたどれるため、現地でその箇所を探すときや、修繕会社に「この写真の場所」と伝えるときにも迷いません。

## 報告書で分かること・分からないこと

**分かること**

- 外から見える劣化の場所と範囲（ひび割れ、欠け、さび、屋根材のずれ、雨樋の詰まりなど）
- 赤外線で撮影した場合の、温度の異常がある場所（浮きの可能性、太陽光パネルのホットスポットの候補など）
- 建物全体の中で、劣化が集中している面や場所

**分からないこと（別の確認が必要なこと）**

- 劣化の**原因**（雨漏りの経路、下地や内部の状態など）
- 浮きや異常の**確定**（赤外線で分かるのは「可能性がある範囲」です）
- 修繕が**必要かどうか、どの工法にするか**の判断

報告書の「異常の候補」は、**詳しい調査をどこに絞って行うかを決める材料**です。打診や散水試験、建築士・施工会社による診断と組み合わせて使います。

## 報告書の使い方

- **修繕の見積依頼**：同じ報告書を複数の施工会社に渡せば、前提をそろえて見積を比べられます。
- **社内・管理組合への説明**：写真と位置図があるため、工事が必要な理由を示しやすくなります。
- **次回の点検との比較**：同じ位置から撮った写真を並べると、劣化の進み方が分かります。
- **保険の相談**：台風などのあとの被害の記録として、保険会社に状況を伝える資料になります（保険の適用を保証するものではありません）。

## 依頼の前に確認したいこと

1. **報告書の形式**：PDFか、紙か、写真データも一緒にもらえるか。
2. **納期**：撮影から報告書の提出まで何日かかるか。
3. **写真データの扱い**：元の写真を受け取れるか。
4. **赤外線の判定の根拠**：温度の異常をどのように判定したか、条件（天候・時間帯）が記録されているか。
5. **追加の調査が必要な場合の相談先**：打診などが必要になったときに、どこに相談できるか。

ドローン点検の報告書は、撮影位置図・番号付きの写真・異常の候補の一覧を番号でつなぎ、修繕の見積や社内の報告にそのまま使える形にしたものです。施設診断技研では、関東（[東京](/areas/tokyo)・[神奈川](/areas/kanagawa)・[埼玉](/areas/saitama)・[千葉](/areas/chiba)・[群馬](/areas/gunma)・[栃木](/areas/tochigi)）の建物・設備の点検結果を、報告書と撮影データでお渡しします。工場・倉庫の屋根は [工場・倉庫の屋根点検](/guides/factory-roof-inspection)、管理会社さま・施工会社さまは [施工会社・管理会社さまへ](/partners) もご覧ください。
