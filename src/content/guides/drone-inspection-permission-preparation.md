建物や設備のドローン点検を外部に依頼する場合、**航空法などにもとづく飛行の許可・承認の手続きは、通常、飛行させる側（依頼先）が行います。** 施設の管理者やオーナー側にお願いするのは、敷地の上空を飛行・離着陸することへの同意、入居者や近隣へのお知らせ、図面の提供、当日の立入管理への協力などです。

## 依頼先が行うこと

| 項目 | 内容 |
| --- | --- |
| 機体の登録 | 100g以上のドローンは、国への機体登録が必要です。 |
| 飛行の許可・承認 | 人口集中地区の上空、空港周辺、人や建物から30m未満での飛行など、航空法で定められた飛行にあたる場合は、事前に国土交通大臣の許可・承認を受けます。 |
| 飛行禁止区域の確認 | 国の重要施設などの周辺は、小型無人機等飛行禁止法により原則として飛行が禁止されています。対象の区域かどうかを確認します。 |
| 飛行計画と安全対策 | 撮影ルート、離着陸の場所、立入管理の範囲、中止する気象条件（風速など）を決めます。 |
| 撮影と報告 | 撮影した写真を整理し、報告書にまとめます。 |

建物の点検では、建物に近づいて撮影するため、**人や物件から30m未満の飛行**にあたる場面が多くあります。また、関東の市街地の多くは人口集中地区にあたります。都県ごとの注意点は [東京](/areas/tokyo)・[神奈川](/areas/kanagawa)・[埼玉](/areas/saitama)・[千葉](/areas/chiba)・[群馬](/areas/gunma)・[栃木](/areas/tochigi) の各ページで紹介しています。

## 施設側で準備していただくこと

1. **敷地の上空を飛ぶことへの同意**：点検する建物の敷地で離着陸・飛行することについて、建物の所有者や管理者の了解が必要です。隣の敷地の上空を通る場合は、その所有者への確認が必要になることもあります。
2. **図面や過去の資料**：立面図・屋根の平面図、過去の点検記録や修繕の履歴があると、撮影の計画と報告の整理がスムーズです。
3. **入居者・近隣へのお知らせ**：マンションやオフィスでは、窓の近くをドローンが飛ぶため、撮影日と時間帯を掲示などで事前に知らせます。洗濯物やカーテンへの配慮もお願いします。
4. **当日の立入管理への協力**：離着陸の場所や、飛行する範囲の下に人が入らないよう、駐車場や通路の一部を一時的に使えないようにする場合があります。
5. **施設のルールの共有**：工場や倉庫では、立入区域、作業時間、火気・電波に関するルールなど、敷地内の決まりを事前に教えてください。

## 依頼の前に決めておくとよいこと

- **点検の目的**：劣化の範囲を知りたいのか、修繕の見積に使いたいのか、台風のあとの被害確認なのかで、撮影の範囲と報告の形が変わります。
- **対象の範囲**：外壁の全面か、屋根・屋上だけか、特定の面だけか。
- **日程の幅**：雨や強風の日は飛行できないため、予備日を含めて候補日を幅を持たせて決めます。
- **立ち会いの要否**：当日に立ち会いが必要かどうかを相談します。

## 法定点検として使いたい場合

建築基準法に基づく定期調査（いわゆる12条点検）の外壁調査として扱うには、調査を行う資格者や調査の方法などに条件があります。法定の調査として使いたい場合は、建物の調査者の方とあわせてご相談ください。赤外線調査の詳細は [赤外線外壁調査の解説](/guides/infrared-exterior-wall-inspection) をご覧ください。

ドローン点検の許可や安全対策は、通常は依頼先が行います。施設側は、敷地を使うことへの同意、入居者・近隣へのお知らせ、図面の提供、当日の立入管理への協力を準備しておくと、点検をスムーズに進められます。管理会社さま・施工会社さまからのご依頼は [施工会社・管理会社さまへ](/partners) もご覧ください。
