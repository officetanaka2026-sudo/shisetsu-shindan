**12条点検（建築基準法第12条の定期報告）の外壁調査は、条件を満たせばドローンによる赤外線調査で行えます。** 令和4年1月の告示改正で、テストハンマーによる打診と同等以上の精度があれば、無人航空機（ドローン）による赤外線調査も使えることが明確になりました。ただし、天候や外壁の条件で使えない部分があり、調査全体は建築士などの資格者がまとめる必要があります。

## 12条点検の外壁調査とは

建築基準法第12条では、一定の用途・規模の建築物（特定建築物）について、所有者や管理者が定期的に建物の状態を調査し、特定行政庁へ報告することを定めています。調査項目の1つが、**タイル、石貼り、モルタルなどの外壁の劣化・損傷**です。

外壁の調査は、通常の定期調査では手の届く範囲の打診と目視で行います。そのうえで、**竣工、外壁改修、または前回の全面的な打診などから10年を超えた最初の調査では、落下によって歩行者などに危害を加えるおそれのある部分を全面的に調べる**必要があります（例外となる条件もあります）。この「全面打診等」の負担が大きく、足場やゴンドラ、高所作業車の費用がかかることが課題でした。

対象となる建物や報告の時期は、特定行政庁（都道府県や市など）ごとに定められています。お持ちの建物が対象かどうかは、まず所管の特定行政庁の案内をご確認ください。

## 令和4年の告示改正で変わったこと

国土交通省は、定期調査の方法を定めた告示（平成20年国土交通省告示第282号）を令和4年1月18日に改正しました。外壁タイル等の調査について、**テストハンマーによる打診と同等以上の精度を有する無人航空機による赤外線調査**を、打診以外の方法として明確にしています。

あわせて、具体的な進め方を示した「定期報告制度における赤外線調査（無人航空機による赤外線調査を含む）による外壁調査ガイドライン」が公表されています。ドローンの赤外線調査を12条点検に使う場合は、このガイドラインに沿って計画・実施・報告することが前提になります。

赤外線調査の仕組みそのものは [赤外線外壁調査とは](/guides/infrared-exterior-wall-inspection) で解説しています。

## ドローンの赤外線調査を使える条件

赤外線調査は、外壁の表面温度の差から「浮き」が疑われる箇所を見つける方法です。温度差が出にくい条件では、浮きを見落とすおそれがあります。ガイドラインでは、事前調査で次のような点を確認し、**赤外線調査に向く部分と向かない部分を分けて計画する**ことを求めています。

| 確認すること | 内容 |
| --- | --- |
| 気象条件 | 天候、気温、風速など。曇天や強風、降雨の直後は温度差が出にくい |
| 日射と時間帯 | 外壁に日が当たる時間帯か、温度変化が出る時間帯に撮影できるか |
| 周辺環境 | 周りの建物からの放射熱や反射の影響がないか |
| 仕上げ材 | タイルの種類など、赤外線で判定しやすい仕上げか |
| 撮影条件 | 外壁からの距離と撮影角度を確保できるか |
| 調査が難しい部位 | 軒裏、出隅、入隅など、熱画像で判定しにくい部分 |

赤外線で判定が難しい部位は、撮影条件を変えるか、打診で調べます。**すべての外壁をドローンだけで済ませられるとは限らない**点に注意が必要です。

## 打診との併用と、精度の確かめ方

ガイドラインでは、調査を始める前に**同じ部位で打診と赤外線調査を同じような条件で行い、赤外線で浮きを検出できるかを確かめる**ことを求めています。そのうえで、撮影した熱画像はすべて保存し、反射などの影響を取り除きながら浮きを判定します。

つまり、ドローンの赤外線調査は打診を完全になくすものではなく、**手の届かない広い面を効率よく調べ、打診は必要な部分に絞る**ための方法と考えると分かりやすいです。足場を組む場合との比較は [ドローン点検と足場点検の違い](/guides/drone-vs-scaffold-inspection) をご覧ください。

## 必要な体制：誰が何を担当するか

ガイドラインでは、役割ごとに次のような担当者を置くことになっています。

1. **外壁調査実施者**：一級・二級建築士、または特定建築物調査員などの資格者。調査全体を統括し、「著しい浮き」の有無を判定します。
2. **赤外線調査実施者**：建築物と赤外線調査の知識・実務経験がある人。撮影、分析、浮きの判定を行います。
3. **ドローン調査安全管理者**：建築物調査とドローン飛行の知識がある人。操縦者や補助者をまとめ、飛行の可否や中止を判断します。
4. **操縦者**：ドローンの飛行技術と操縦経験がある人。

定期報告書を作成・提出するのは、資格をもつ調査者です。ドローンの撮影会社だけで12条点検の報告が完結するわけではないため、**依頼するときは、建築士や調査会社とドローン撮影の担当がどう連携するかを確認する**ことが大切です。

## 依頼する前に確認しておきたいこと

- **建物が定期報告の対象か、今回が全面打診等の時期か**：竣工や前回の外壁改修・全面打診からの年数を確認します。
- **外壁の仕上げ材と面積**：タイル、モルタルなどの種類と、調査が必要な面の面積をまとめておくと、見積もりが早くなります。
- **周辺環境**：道路や隣地との距離、人通り、空港の近くかどうかなど。ドローンの飛行には航空法などにもとづく許可・承認が必要な場合があります。
- **報告書の形式**：外壁調査結果図、熱画像と可視画像、飛行計画書など、定期報告に必要な資料がそろうかを確認します。
- **撮影できなかった部分の扱い**：天候や条件が合わず赤外線で判定できなかった部分を、打診などでどう補うか。

当社では、提携パイロットによる赤外線・可視光の撮影と、撮影位置・写真番号をそろえたデータの整理を行います。定期報告については、建築士・調査会社の方と連携して進めることを前提にご相談ください。費用の考え方は [ドローン外壁調査の費用の目安](/guides/drone-exterior-wall-inspection-cost) で解説しています。
